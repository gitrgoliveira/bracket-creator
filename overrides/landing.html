How it works

From the draw to the final, in one app

Load your participant list, draw pools and brackets, then run every court from a laptop or tablet. Results flow to the court displays and to phones as each point is scored.

Features

Made for the day of the tournament

Built with tournament organisers, for court operators who may be new to the job.

Get started

Up and running in a few minutes

  1. Install bracket-creator on macOS, Windows or Linux. Prefer containers? Use the Docker option.
  2. Start it on the laptop at the desk.
  3. Open it in a browser, then share the laptop's network address with the courts and the hall.
Run your first tournament 
# start the tournament app; --bind 0.0.0.0
# lets the courts and phones reach it
bracket-creator mobile-app --folder ./tournament-data \
  --bind 0.0.0.0

# then open
http://localhost:8080        # on this laptop
http://<laptop address>:8080  # on courts and phones
